# Files

Independent Strata-derived Rust/GTK4 file manager. Preserve MIT and third-party notices, preview sandboxing, existing widgets, localization, and filesystem safety. Use existing preference and key binding infrastructure.

Build: `cargo build --release --locked`. Install: `./install.sh` (builds this checkout); remove: `./uninstall.sh`.
Run targeted checks only, with private display/D-Bus for GUI tests (`./scripts/test-gtk.sh <filter>`). Display name Files; binary nyx-files; application ID io.github.design_nexus.nyx.Files.
Use public pinned dependencies across repositories. No upstream compatibility requirement.
